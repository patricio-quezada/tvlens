# Style, match the existing TVLens identity

The look already exists on the landing page (`landing-page.html`, live at tvlens.org).
The show-detail page must feel like the same product. Pull from there. Summary below.

## Mood
Cinematic, dark, film-grain texture, a single warm amber accent glowing against near-black.
Restrained and premium, not busy. Think a quiet movie title card, not a busy dashboard.

## Palette
- Background, deep: `#08080a`
- Card / raised surface: `#111115`
- Text, primary: `#f0ebe3` (warm off-white)
- Text, secondary: `#7a756c`
- Text, muted: `#4a463f`
- Accent, amber: `#e89b2d`
- Accent glow / hover: `#f5a623`
- Accent, dim: `#c27d1a`

## Type
- Display / headings: **Bebas Neue** (tall, condensed, uppercase, wide letter-spacing).
  Used for the logo and section titles.
- Body / UI: **DM Sans** (light and regular weights), line-height ~1.6.
- Numbers and labels can borrow the Bebas Neue treatment (uppercase, letter-spaced).

## Texture and light
- A faint film-grain overlay across the whole page (very low opacity, ~0.035).
- A soft amber radial glow near the top, and a subtle horizontal light streak, both very
  low opacity. Atmosphere, not decoration.

## Motion
- Gentle fade-up on load, staggered by section (~0.15s apart).
- The amber can pulse very slightly on a status dot or a live element. Keep it subtle.

## Feel to preserve
The landing page reads like the opening of a prestige show. The detail page should feel
like the same world, just with real content in it. Amber is the only color that gets to
be loud; everything else stays quiet.
