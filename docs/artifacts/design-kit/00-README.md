# TVLens, show-detail page, design kit

This folder is everything needed to wireframe and brainstorm the **show-detail page** for
TVLens: a page that shows one TV show plus the shows most similar to it. Read the files
in order.

- **01-BRIEF.md** — what the page is, its goal, and the sections it needs.
- **02-STYLE.md** — the visual identity (colors, fonts, mood) to match.
- **landing-page.html** — the real, live landing page (tvlens.org). Use it as the exact
  style anchor: pull the palette, type, and grain from here so the new page feels like
  the same product.
- **03-sample-data.md** / **03-sample-data.json** — real output from the recommender for
  three shows. Design with this content, not placeholder text.
- **04-data-model.md** — the fields actually available for a show, so the design only
  shows data that exists.

The one idea to keep front of mind: TVLens recommends shows through **the people who made
them**. The similar-shows list is not the feature. The *named people who connect two
shows* is the feature. Design so that "why" is impossible to miss.
